Icons
Infinity Icons HU Infinity-Icons-HU.otf
Custom game icon font · used for HUD icons and UI symbols. Showing U+0021–U+00E9, U+25AB, U+2606, U+2620, U+2690, U+2693, U+26D0–U+26EF, and U+26FF, excluding non-icon punctuation and gaps with no glyphs in the font. Tiles outlined in green and tagged IN USE are glyphs actually referenced by a scene, prefab, or script today; tiles outlined in amber and tagged PLANNED are allocated to a design stub in entity-reference.html but not yet baked into a prefab. Hover any highlighted tile for where/what.
